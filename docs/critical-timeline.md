# 关键节点与 VAD 时间轴

报告总览和单轮页共用同一组事件位置。一行只比较两个点：左侧固定显示比较对象与时间差，右侧在真实位置显示点位、精确时间与连接线。相邻标签上下错开，不把多组点和差值堆进同一行。点击连接线可选中两端区间；缩放、拖动测量和磁吸继续可用。

工具栏「显示」提供三个选项：只看关键点、只看详细环节、全部显示。浏览器记住选择，总览与单轮页共用；浏览器禁止本地存储时，切换仍正常。切换保留时间坐标、缩放、选区及详细行的展开状态，隐藏点不参与磁吸。旧报告缺少关键点行时默认显示详细环节。VAS 的本地 VAD 与 ASR VAD 事件保留独立 VAD 行。

|模式|输入节点|
|---|---|
|PTT/manual|实际第一帧发出（first_audio_sent 或浏览器首个 input_audio_frame_sent）、listen_stop_sent|
|VAD/auto/realtime|local_vad_endpoint_detected、asr_endpoint_detected|

两种模式的后续节点：asr_final、每次 LLM 的请求提交与首包、tts_first_pcm、通过现有播放时钟校验的客户端首帧播放。

- ASR 完成采用最终识别文本事件，不采用连接关闭事件。
- 每个 turn 内按请求标识和时钟区分 LLM #1、#2……，分别显示提交到首包的耗时。首包明确区分文字与工具增量，不利用 TTS 文本倒推缺失的文字事件。
- TTS 只沿同一时钟内的显式父 span 关联 LLM。共同 chat 父节点或时间接近都不足以证明归属；未知时显示「LLM 归属未采集」，改为比较 TTS 提交到首音，避免把第二次 LLM 接到第一次过渡语上。
- 过渡语、临时回复和正式回复分别保留；首音到播放通过已校验的音频包序号匹配到对应声音。缺少首音或播放关联时显示未采集。
- VAD 的两个独立检测器分别与 ASR 最终结果比较，不把本地 VAD 和 ASR VAD 当成必须依次发生的串行环节。
- Python 模拟播放明确标记「模拟」，不冒充浏览器扬声器实际播放；无法验证的浏览器播放点不补造。
- 同一时钟用 monotonic 时间差。跨端只显示未校时墙钟差，虚线和 ≈ 提示；没有共同墙钟时不计算跨端间隔。未做自动校时，也未改变原始事件或音频时刻。
- 没有对应事件时写「未采集」，不推断为该功能关闭。
